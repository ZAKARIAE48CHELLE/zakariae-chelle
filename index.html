01AI / LLMOps

LocalOps AI

Privacy-preserving incident triage & root cause analysis

A local incident triage and root cause analysis system built on a small language model fine-tuned with QLoRA. It adds severity calibration, RAG over operational runbooks, FastAPI services, Prometheus monitoring, Docker deployment and a web dashboard.

Problem
Help operators classify incidents and understand likely root causes, without sending data to a third party.
AI core
Fine-tuned SLM (QLoRA) with severity calibration, grounded by RAG over runbooks.
System
FastAPI services, Prometheus monitoring, a web dashboard and Docker deployment.
Value
Local, privacy-preserving intelligence for operational support.

02Data science / Business AIInternship project

Digital Twin Client Classification

Dynamic classification of prospects & clients

An AI platform that classifies prospects and customers dynamically using digital twins. It combines AHP-weighted RFM-ES scoring, CLV, churn and conversion models, segmentation and personas, and A/B simulation — on PostgreSQL and Streamlit, supervised by LangGraph agents and a governed local LLM with human validation.

Problem
Give businesses a living view of who their prospects and customers are, and how each is likely to behave.
AI core
RFM-ES/AHP scoring, CLV, churn and conversion models, dynamic personas, and a governed local LLM.
System
PostgreSQL data layer, Streamlit interface, LangGraph multi-agent supervision with human validation.
Value
Actionable segmentation for marketing and customer intelligence.

  • RFM-ES / AHP
  • CLV
